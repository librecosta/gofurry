## Public profile

- CN and INTL serve a regional, bilingual SSR profile at the existing Public ID and slug URL. It uses the reviewed logo, category, tags, supported languages and safe addresses. Names and summaries come from editorial translations. A missing translation shows the actual source language, uses `noindex` and omits metadata for the missing translation. Slug aliases return 301 to the existing canonical route.
- The directory, discovery and profile use internal navigation. Chromium verified that returning from a profile preserves the filtered directory URL and its scroll position. Start's existing Sites item opens the localized channel as a keyboard-accessible link. Its popover closes on activation.
- Primary and alternate addresses are native external links. Labels show the host. Existing D2-A click reporting runs beside navigation and visible dwell remains three seconds. Recent activity uses the same seven UTC dates and the existing threshold of 10 effective events on at least two dates. The UI displays qualifying views and clicks and omits zero or insufficient counts.
- Related results require a shared category or at least two shared tags. The order is same primary category, primary-to-supplemental, shared supplemental, number of tags, number of languages, available Heat v1 tie-breaker and Public ID. The result caps at six reviewed SFW Sites in the same regional database.
- Technology shows up to five allowed HTTP responses, TLS confirmations or medium/high-confidence fingerprints from the active Consumer projection. It verifies the approved primary address, binding, plan scope, rule version and a confirmation within 30 days. A recorded 410 hides the affected generation until activation of its replacement. Each displayed fact includes its source host and last confirmation time, with a first-observed date when the ledger can attribute that value and ruleset. Published Yearbooks keep their existing dates, versions, URLs and visibility. Older compatible D1 profiles remain reachable with `noindex` and retain their published Yearbook links.

## Schema, CLI and API

The forward Goose migration `202611120003_site_profile.sql` adds `site_localizations.body` and nullable `collection_gaps.prior_generation`. The body defaults to empty. The gap field identifies the exact superseded Consumer generation across repeated resets within one epoch. The migration adds no tables, foreign keys, cascades or indexes.

```sh
task migrate ACTION=up CONFIG=/path/to/private-api.yaml
go -C services/api run ./cmd/api --config /path/to/private-api.yaml navigation inspect PUBLIC_ID
go -C services/api run ./cmd/api --config /path/to/private-api.yaml site-profile set-description PUBLIC_ID en REVISION /path/to/reviewed-text.txt --confirm-reviewed
```

Use `zh` to update the Chinese localization. Use `-` to clear the selected body. Each existing locale accepts at most 10 KiB of UTF-8 plain text. Blank lines separate paragraphs. The command rejects markup, checks the Site revision and reports the resulting revision and CLI source without logging the text. Ordinary Site edits preserve the bodies of retained locales.

| Read | Contract |
| --- | --- |
| `GET /api/v1/sites/:publicID` | Existing identity and addresses plus reviewed profile fields and a bounded technology summary. Compatible unreviewed profiles receive the minimal representation. |
| `GET /api/v1/sites/:publicID?profile=1` | Adds the related list, eligible statistics and published years for SSR in one regional API request. |
| `GET /api/v1/sites/:publicID/related` | Returns up to six compact profiles. Restricted, draft, archived and legacy-unreviewed subjects return 404. The existing Site API rate limit applies. |
