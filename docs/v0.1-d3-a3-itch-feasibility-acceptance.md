# D3-A3 验收 · itch.io 来源可行性

**结论：RSS-ONLY。** itch.io 官方游戏 Feed 可作为有限窗口内的候选线索。本阶段保留 GoFurry 现有 `itch_io` 官方链接与受控关联能力。公开样本的身份稳定性、资料授权与正面 SFW 证据不足以支持自动接入。本次验收未新增 Provider、定时轮询、迁移或自动建档。

## 能力矩阵

| 能力 | 可核验来源与实测 | A3 边界 |
| --- | --- | --- |
| 第三方作品 API | `GET https://api.itch.io/profile/games` 匿名返回 `401` JSON。官方文档把作品列表与作品管理限定于凭据对应账号有权编辑的范围。`wharf/latest` 可匿名查指定构建渠道的用户版本，只返回版本字段。[Server-side API](https://itch.io/docs/api/serverside) · [OAuth](https://itch.io/docs/api/oauth) | 第三方目录与通用详情 `unsupported`。创作者授权可提供其管理作品的数字 ID、基础资料和部分运营数据，需另行限定权限与用途。 |
| 浏览器 API | 官方 `Itch.getGameData` 用于购买组件，按 `user/game` 返回少量资料，示例含 ID、标题、价格和奖励。A3 仅核查文档。[JavaScript API](https://itch.io/docs/api/javascript#itchgetgamedataoptions) | 未证实存在可长期使用的服务端详情契约，未使用底层请求或草稿访问参数。 |
| 发现与时间 | 新上传、首页精选和标签 Feed 返回 RSS 样本。`pubDate`、`createDate`、`updateDate` 均存在。新上传窗口的 `pubDate` 和 `updateDate` 实际乱序。重复请求及 `?page=2` 返回相同 36 个 GUID，未见下一页链接。[API Overview](https://itch.io/docs/api/overview#rss-feeds) · [官方 Feed 说明](https://itch.io/updates/rss-feeds-for-browsing-games) | 可以发现当前窗口中的候选。无可确认的历史回填、单调游标或分页。日期保留为上游信号，无法据此判定作品发行或目录收录时间。 |
| 作品身份与更名 | 三份游戏 Feed 共 82 个条目，每个 GUID 都等于同条作品 URL。itch.io 文档说明作品 slug 与创作者名均可变更并由平台重定向。[作品 URL 重定向](https://itch.io/updates/old-game-urls-will-redirect-to-most-recent-if-changed) · [用户名变更](https://itch.io/updates/change-your-username-url) | 同一窗口可按规范 `creator/game` 去重。Feed GUID 无法证明更名前后身份。保留现有 GameSource 键和 Game Public ID。 |
| 名称、简介与封面 | 游戏 Feed 样本有 `plainTitle`、`description` 和 `imageurl`。两页样本有标题、Open Graph 简介和图像、JSON-LD。图片 URL 只检查是否存在。[A Short Hike](https://adamgryu.itch.io/a-short-hike) · [CELESTE Classic](https://maddymakesgamesinc.itch.io/celesteclassic) | 标题和链接有候选价值。简介字段可能包含 HTML，封面需要独立使用权。未复制正文或下载、转载、热链素材。 |
| 类型、平台、开发者、发行与可获取状态 | 三份 Feed 未提供可独立使用的作者、类型或发行状态。两次相同的新上传窗口均有 `platforms` 元素，36/36 内容为空。两页的可见资料能提供类型、标签、作者、平台和状态，但字段并不齐全，CELESTE Classic 未显示公开发行日。[页面设计说明](https://itch.io/docs/creators/design) · [索引条件](https://itch.io/docs/creators/getting-indexed) · [访问规则](https://itch.io/docs/creators/access-control) | 页面字段属样本验证，缺失保持 Unknown。公开页面与平台实际可下载、购买、试玩状态分别判断。 |
| 成人内容与 SFW | 官方要求作者标记成人内容，匿名浏览默认过滤已标记作品，这 82 个 Feed 条目均无显式内容分级字段。[创作者内容规范](https://itch.io/docs/creators/quality-guidelines#adult-content-must-be-labeled) · [索引规则](https://itch.io/docs/creators/getting-indexed) | `unsupported`。作品出现在 Feed 或缺少成人标记，不提供正面 SFW 证据。标签只提供题材线索。 |
| Steam 作品关联 | A Short Hike 的 itch.io 页面有指向 Steam AppID `1055540` 的链接，作者的作品官网同时链接两个商店。CELESTE Classic 提到重制的完整 PC 作品，样本无直接 Steam App 链接。[A Short Hike 官方站](https://ashorthike.com/) · [CELESTE Classic](https://maddymakesgamesinc.itch.io/celesteclassic) | 第一例有可复核的作品级佐证。后一例不能因相似名称或同开发者合并。Feed 样本未提供结构化跨商店关系。 |
| 价格、销量、下载量、在线人数、动态 | 游戏 Feed 有 `price`／`currency` 字段。公开价格可受最低价、任意付款、促销及时间影响。授权 API 文档中的购买和下载计数属于相关账号。官方另提供作品 `/devlog.rss`。[Server-side API](https://itch.io/docs/api/serverside#profilegames) · [购买说明](https://itch.io/docs/creators/how-buying-works) · [Devlog RSS](https://itch.io/updates/updates-to-devlogs) | GoFurry itch.io 价格投影、销量、下载量、在线人数、平台新闻均 `unsupported`。Devlog 仅是可选创作者动态来源，非全站新闻流，本阶段未导入。 |

## 访问边界与实际采样

公开样本采于 2026-11-14 UTC。使用匿名 HTTPS、标识 User-Agent、12 秒请求超时和每响应 256 KiB 上限。未跟随重定向、访问下载或嵌入路径、登录、换代理规避限流。原始 HTML／XML 仅在内存检查，报告只保留测量结果。主站和两个创作者子域的 `robots.txt` 均为 `200`，所抽查作品页和 Feed 不在相应域的禁止路径内。官方文档明确提供 Feed 阅读器订阅；Terms §3–4 包含信息收集、权利与内容许可约束。未找到可据此确认持续抓取作品 HTML、存储或对外转载简介与素材的授权，也未找到公开请求频率承诺。[主站 robots.txt](https://itch.io/robots.txt) · [创作者子域 robots.txt](https://adamgryu.itch.io/robots.txt) · [Terms §3–4](https://itch.io/docs/legal/terms)

| 匿名响应 | 状态 | 体积 | 实际内容 |
| --- | ---: | ---: | --- |
| [/feed/new.xml](https://itch.io/feed/new.xml) | 200 | 27,501 B | 36 条，`pubDate` 有 15 次相邻升序跳转 |
| [/feed/featured.xml](https://itch.io/feed/featured.xml) | 200 | 7,555 B | 10 条；独立文档浏览工具的同一路径曾报 429，未在该工具重试 |
| [/games/tag-furry.xml](https://itch.io/games/tag-furry.xml) | 200 | 28,107 B | 36 条，`pubDate` 跨 2017–2026 年，16 次相邻升序跳转 |
| [/feed/sales.xml](https://itch.io/feed/sales.xml) | 200 | 144 B | 空 RSS，仅代表该次结果 |
| 两个公开作品页 | 200 / 200 | 41,736 / 27,416 B | 两者均有 `og:description`、`og:image` 和 JSON-LD，均无 `rel=canonical` |
| [A Short Hike 的 Devlog](https://adamgryu.itch.io/a-short-hike/devlog.rss) / [CELESTE Classic 的 Devlog](https://maddymakesgamesinc.itch.io/celesteclassic/devlog.rss) | 200 / 404 | 5,626 B / — | 前者有 8 条，后者此路径未返回 Feed |

同一轮的三次新上传请求各 27,402 B，返回的 36 个 GUID 完全重叠，均未返回 `ETag`、`Last-Modified` 或 `Cache-Control`。该三次用时 0.75–3.28 秒，其他游戏 Feed 的首次样本约 7.6–7.9 秒。这些点测不能推断阻断率或服务容量。临时隔离夹具验证按 URL 去重可处理重复、乱序和重启重放，429 保留上次状态，恢复时仍在当前窗口的条目可以补收。停机期间进入又移出窗口的条目无法从该 Feed 补回。

## GoFurry 回归与后续

使用 `task check:api`、`task sql:check` 和 `task check:collection` 验证既有接口。采集回归使用独立 PostgreSQL 18.6、Redis 8.2.1 与固定 Harvest `349730b5c3ff57be084dfac72dfb77f19dacb54c`，上游用夹具模拟。D3-A1 已有测试覆盖规范 `creator/game`、双向证据关联、两个既有 Game 保持各自 Public ID 及撤销来源。D3-A2-B 检查 410 重建和停更 31／181／365 天仍可读取已发布资料。现有 Intake 测试中两个操作与后台 Consumer 竞争命名空间锁，本次仅在测试中有界重试锁忙状态，其余错误仍立即失败。测试未将公开样本写入任何数据库。[GoFurry develop CI](https://github.com/librecosta/gofurry/actions/workflows/check.yml?query=branch%3Adevelop) · [Harvest 固定版本 CI](https://github.com/librecosta/harvest/actions/runs/43573570774)

D3-B 可直接使用既有 Game 身份与平台链接。将来若有明确的 Feed 聚合授权或创作者授权，可重新评估受限轮询、稳定作品标识、内容使用权及能证明 SFW 的分级来源。A3 到此结束。
