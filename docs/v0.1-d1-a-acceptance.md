# D1-A acceptance

## Identity and storage

Migration `202611110001_site_game_identity.sql` creates `sites`, `site_localizations`, `site_addresses`, `games`, `game_localizations` and `game_sources`. Goose runs only by explicit command. The integration fixture applied the two wallpaper migrations first, inserted a Published wallpaper, applied D1-A and repeated `up`. The same wallpaper ID, title and revision remained readable through the existing public API.

Each parent has a Go UUIDv7 key, immutable 16-character Public ID, editable slug, publication timestamps and optimistic revision. Editing validates the complete new child set and commits it with the parent revision. Site publication requires one primary address and at least one localization. Removed addresses and platform sources are deactivated, and a platform identity remains reserved to its Game. Games can publish with no platform sources.

## Published paths and read contracts

| Fixture | CN default and alternate | INTL default and alternate |
| --- | --- | --- |
| Site, 示例社区 / Example Community | `/sites/000000000000000a/example-community`, `/en/sites/000000000000000a/example-community` | `/sites/000000000000000a/example-community`, `/zh/sites/000000000000000a/example-community` |
| Game, Orbit Game | `/en/games/000000000000000b/orbit-game` | `/games/000000000000000b/orbit-game` |

The Site fixture uses `https://example.com/new/Community?tag=art&tag=games` and an alternate address. The Game fixture uses Steam AppID 42 and a manually recorded itch.io source. The CN default Game URL displays the English name with its source language and explicitly marks the Chinese translation unavailable. It has no Chinese description, canonical or Chinese hreflang. Canonical and hreflang are scoped to actual local translations and the configured `WEB_PUBLIC_ORIGIN`. Normal published API and indexable HTML responses are cacheable for 60 seconds. Redirects and error responses are no-store.

Public read endpoints are `/api/v1/sites`, `/api/v1/games` and their typed Public ID details. List pages default to 20, allow up to 50 and use the last returned Public ID as an opaque keyset cursor when another page exists. Drafts and archived entities return 404. API and SSR return 503 when the local database is unavailable.

## Executed verification

- `task check:catalog` used PostgreSQL 18.6 with separate CN and INTL databases, two Fiber processes and two Web processes from the production build. It verified 12,000 UUIDv7 and 12,000 Public ID generations, collision retry, immutability, duplicate slugs and hosts, FK/partial uniqueness, a racing revision, publication prerequisites, address edits, Steam normalization, duplicate ownership rejection, source removal and regional projection with separate local UUIDs.
- Six Playwright checks exercised actual SSR 200/301/404, canonical/hreflang, missing translations, unpublished exclusion, cache headers, read-only routes, Start, wallpapers, and deterministic legacy-map redirects against published records. Pausing PostgreSQL returned API and SSR 503, Start remained 200, and both catalog reads recovered when PostgreSQL resumed.
- Go vet, unit tests and build, Web production build and typecheck, `task sql:check`, two HMR checks and the isolated wallpaper schema checks passed. Compose configuration validated. A local image rebuild stopped at Docker Hub authentication transport errors.
- The full Windows Chrome regression suite reported 82 passed, 3 skipped and 6 Start failures. The four repeatable failures (three compact-layout assertions and a system-theme test logging 503s with no API running) also failed on the pre-D1-A branch. The suggestions and desktop widget checks had timing-dependent results in focused runs.
- The test databases are created for this check and discarded. No persistent development or production data was migrated or reset.
