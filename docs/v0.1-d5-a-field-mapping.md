## 规范化与不迁移的字段

- Go 1.27 JSONv2 按明确源键输出。`source` 含旧库别名、表名、`legacy_id` 和完整键；`raw` 持有受限原值；`candidate` 持有规则 v1 的安全转换；`issues` 保留缺失、冲突和拒绝原因。关系键包含其父记录 ID，孤儿关系仍在包中。
- 旧本地 `timestamp` 原样保留并按 `Asia/Shanghai` 转 UTC。`timestamptz` 由 PostgreSQL 按 UTC 串行化。旧创建时间与首次发布语义分开。双语字段明确标识 `zh-CN` 和 `en`；格式字符、空白和长度按规则处理。文本或 JSON 原字段超过 8 KiB 时写入超限标记并报告。
- HTTP/HTTPS 地址规则去除多余默认端口并规范化域名。拒绝凭据、查询参数、片段、危险路径、内网字面量和本地域名后缀。工具从不解析域名或跟随重定向；URL 候选保留人工或旧配置来源。
- GFA 仅读 `gfa_content_idea.kind` 并按 `game/site/other/unknown` 计数，绝不查询标题、正文、协作人员或账户表。GFA 表缺失或权限不符合时单独汇报。
- 不读取访问统计、国家/公益、评论/IP、用户、抽奖、旧采集配置中的代理、技术事实、Steam 历史或媒体。唯一资产是旧 `gfn_site.icon`。D5-A 的输出不含新站 UUID、Public ID、新身份映射决议或 301。

私有输出与隔离恢复方式见 [D5-A 验收及运行手册](v0.1-d5-a-acceptance.md)。
