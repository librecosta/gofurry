# D4 统一运营后台验收

GoFurry 继续通过独立的 loopback Management Fiber App 提供权威接口。新增接口统一位于 `/internal/v1/ops`，接受绑定地区和运行环境的 Bearer、服务端 Actor 及 Request ID。数据库与 Management 配置即可启用目录管理。站点与壁纸的媒体写入另外依赖已配置的对象存储。

| 操作 | Owner | Operator | Developer |
| --- | --- | --- | --- |
| 查询目录、采集与本人请求回执 | ✓ | ✓ | ✓ |
| 编辑资料、发布、归档、管理合集和固定精选 | ✓ | ✓ | — |
| 提交或重试单个 Steam AppID、暂停/恢复发现、执行一次对账 | ✓ | ✓ | — |
| Site 内容分级、Game 内容封禁或解除、Game 来源纠错 | ✓ | — | — |

- Site 编辑包含双语纯文本、主备地址、分类、标签、语言和已发布年鉴。普通站点可在未分类时发布。Logo 接收正方形 WebP，封面接收 16:9 AVIF。上传由现有存储服务校验、按哈希写入、检查 HEAD、下载和公开交付，然后以匹配的 Site revision 绑定。
- Game 人工编辑沿用原来的优先级。管理读取区分人工资料、持久展示和分平台、语言、地区的采集证据。来源修正继续沿用原有身份约束和绑定关闭机制。Owner 可为已发布且未受限的游戏恢复一个现有 Steam 来源的持续采集，沿用 Intake 原有计划去重。合集保存与成员顺序同事务提交，精选保持三个 Site 槽及六个 Game/合集槽。
- Discovery 展示持久窗口、游标、预算和暂停状态。Consumer 展示最近实际连接结果、本地 ACK 与重建、采集确认时间和历史缺口。无数据时显示未知或无记录。对账只调用本区域现有的 Harvest 写入能力。对账涉及远端调用，成功回执表示一次对账完成，超时可由下一轮后台对账恢复。
- Goose 前向迁移 `202611150002_management_operations.sql` 增加操作回执表和三项采集读取索引。业务变更与本地回执同事务提交，记录 Actor、Request ID、动作、目标、版本和时间。提交后的回执可由发起者查询。Admin 独立保存已请求及已知结果，未知时只读核对。所有改动复用现有目录业务表和公开资格规则。

## 验收

- 使用独立 Admin、GoFurry CN 和 INTL 的 PostgreSQL 18.6 数据库及独立浏览器身份。Admin 的真实 Go Embed 连接 GoFurry 的独立管理监听器。覆盖 Bearer、越权角色、跨区拒绝、公众监听器隔离、CSRF、409 后保留草稿、GoFurry 提交后丢失 HTTP 响应、两端 Request ID 对齐、未分类 Site 发布/归档/恢复、显式成人边界、合集成员排序、390px 页面和壁纸工作区读取。
- Admin 联调中的 Harvest 故障由本机 HTTP 503 上游模拟。真实 Harvest Server/Worker、Redis、模拟 Steam/AI、Consumer 重放与 410 恢复通过原有固定 Harvest 联调入口独立验证。Site 资源测试走隔离 TLS 对象存储；没有访问生产 R2。
- Go、sqlc 与目录回归在本地执行。目录回归包括 CN/INTL、年鉴、Sites 与 Game 详情浏览器及 31/181/365 日的持久发布语义。联调入口在 Admin 的 `scripts/check-gofurry-operations.mjs`。
- 提交版本以包含本报告的 `develop` 提交为准。查看 [GoFurry Foundation checks](https://github.com/librecosta/gofurry/actions/workflows/check.yml) 对应该 SHA 的结果。

## 管理分页实测

Windows 与 Docker PostgreSQL 18.6。预热后各测五次，从 Admin 带会话的 HTTP 入口按关键词查首页及下一页。每页 30 条，游标在第二页没有重复身份。时间包含 Admin、GoFurry 与 PostgreSQL 往返。

| 100 | 8.1 / 9.8 ms | 9.2 / 9.6 ms |
| 1,000 | 8.3 / 9.2 ms | 10.1 / 11.8 ms |
| 10,000 | 18.2 / 19.6 ms | 20.1 / 21.0 ms |

GoFurry Web 与 API 容器通过存活、就绪、非 root、日志轮转和 SIGTERM 检查。本机 Docker Hub 地址无法认证，构建使用同版本官方公共 ECR 镜像。
