在无外网、无宿主端口的 PostgreSQL 18.6 容器中新建目标数据库，显式运行 Goose，并确认首次 `plan` 前身份、业务数据、导入批次与测试桶均为空。对象存储使用同一隔离环境内 TLS S3/CDN 测试替身。

| 步骤 | 实测 |

## 故障与恢复

- **实际归档和真实 Seed。** 用错误的外层 SHA256、独立重算外层 SHA256 的截断压缩包、未迁移库、带一条无关记录的非空库、缺失目标或存储配置、只读 PostgreSQL 账号及 S3 HEAD 403 验证拒绝。非空库的原有记录保留，导入批次为零。
- **进程与 PostgreSQL。** 在首个 Game 插入事务内暂停后向安装进程发送 SIGTERM。247 个已提交 Site 保留，Game 未提交。以同一计划再运行并注入一次 PostgreSQL 写入异常，保留失败回执及待修复的依赖。再次执行完成恢复，验证 5,870 条记录，已提交 Site 的 UUIDv7 与 Public ID 全部保持原值。
- **对象写入。** 注入实际 PUT 503，先成功应用 5,869 条，唯一待重试 Logo 无无效数据库绑定。再次执行补齐一条、复用 5,869 条。最终目标有 223 条合法 Logo 绑定。
- **小型合成归档。** 单测验证不兼容 Schema、伪造的生产标记、归档路径跳转、Windows 绝对路径、硬链接、重复成员、额外数据库文件、缺失或损坏的 Logo 和尾随数据均被拒绝。真实 PostgreSQL 集成测试还检查非空目标、计划重放和人工内容保护。
- 本地通过 `task check:api`、`task sql:check`、`task check:legacy-seed`、`task check:legacy-import` 及单独配置 resvg 0.47.0 的 Logo 渲染测试。

## 私有复现

在仓库外的受限工作目录保存 YAML、归档、计划和报告。所有路径使用绝对路径。首次执行前显式迁移空库。构建 YAML 填写 `archive`、`seed_dir`、`decisions_file`、`snapshot_id`、`backup_sha256`、`content_sha256`。验包 YAML 填写 `archive`、`package_sha256`、`work_dir`。目标操作在同一验包配置中增加 `target`，按现有 D5-B1 格式填写 `region: CN`、`environment: development`、`isolation_token`、`database`，有 Logo 时还须配置 `storage`。归档与计划的 SHA256 各自从核准记录取得。 [D5-B1 操作说明](v0.1-d5-b1-acceptance.md)

```text
go -C services/api run ./cmd/legacy-bootstrap build --config <build.yaml> --report <build-report.json>
go -C services/api run ./cmd/legacy-bootstrap verify --config <verify.yaml> --report <archive-report.json>
go -C services/api run ./cmd/legacy-bootstrap plan --config <install.yaml> --plan <plan.json> --report <dry-run-report.json>
go -C services/api run ./cmd/legacy-bootstrap apply --config <install.yaml> --plan <plan.json> --plan-sha256 <sha256> --report <first-report.json>
go -C services/api run ./cmd/legacy-bootstrap apply --config <install.yaml> --plan <plan.json> --plan-sha256 <sha256> --report <retry-report.json>
go -C services/api run ./cmd/legacy-bootstrap verify-target --config <install.yaml> --plan <plan.json> --plan-sha256 <sha256> --report <verification-report.json>
```

每次命令使用新的报告路径。重试沿用同一归档、目标、计划及校验值。有效重跑只允许全新目标或注册了同一计划的目标。归档暂存目录在命令退出时清理。执行报告、对账指纹、测试日志和原始归档留在私有工作区。
