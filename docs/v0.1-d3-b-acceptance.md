# D3-B 游戏频道验收

## 交付

- `/games` 提供搜索、可选三槽游戏精选、最近收录、即将发售、近期发售、类型、当前 Steam 优惠、精选合集和官方动态。Start 的 Games 菜单项进入对应语言的频道。
- `/games/directory` 通过 `GET /api/v1/games/directory` 支持 `q`、逗号分隔的 `genre`（OR）、`store`、`system`、`phase`、Steam `price`、`sort`、`after`。默认 24 条，API 最大 48 条。支持首次收录、名称、确切发行日和确切预计发行日排序。目录页次写入 URL，浏览器返回恢复筛选、页次和滚动位置。
- `/games/collections` 和 `/games/collections/{public_id}/{slug}` 对应 `GET /api/v1/games/collections` 和 `GET /api/v1/games/collections/{publicID}`。列表支持合集搜索和游标，详情支持策展顺序与发行时间线。归档或阻止公开的游戏只从成员读结果滤除。
- `GET /api/v1/games/discovery` 返回固定版块。查询读取对应地区 PostgreSQL。CN 默认中文，INTL 默认英文。筛选、分页和缺少当前语言译文的合集页使用 `noindex, follow`。规范路径 301，缺失 404，非法查询 400，数据库不可用 503。
- Goose `202611140002_game_channel.sql` 增加首次公开时间、合集、成员、六个可选精选位和紧凑的 Steam 来源投影。首次公开时间取已有发布记录，恢复公开保留原值。沿用 UUIDv7、随机 16 位 Public ID 和人工文案优先级。无新增外键。迁移须显式执行。
- 类型依据 Steam Genre ID，支持系统依据实际声明。发行状态取 `coming_soon`，只有通过日历验证的确切日期参与日级排序。逾期的预计日期保留为预计。Steam 官方域封面经服务端和浏览器复核。报价使用 48 小时内、店区与币种匹配的确认数据，CN 为 CN/CNY，INTL 为 US/USD，并校验绑定与出口。Steam 零金额与明确 Free 独立判定。官方动态须使用对应 App 的官方文章 URL。

旧站只读参考了游戏首页的编辑入口和自动发现、搜索的共享 URL、合集的发行时间线。

## 私有 CLI

使用 `api --config <private-yaml> game-channel`。`create EDITORIAL_JSON` 使用包含 `slug` 和 `localizations` 的 JSON 文件，每条文案含 `locale`、`name`、可选 `summary`。`inspect PUBLIC_ID` 获取 revision 和成员。`edit PUBLIC_ID REVISION EDITORIAL_JSON` 更新双语资料，`members PUBLIC_ID REVISION ORDERED_PUBLIC_IDS_JSON` 以 Public ID 数组替换顺序，`status PUBLIC_ID REVISION published|archived` 发布或归档。`features` 查看槽位和 revision，`feature SLOT REVISION PUBLIC_ID_OR_DASH` 设置或清除。普通游戏继续由现有 Intake 发布。

## 隔离验收

- 运行 GoFurry、固定 Harvest `349730b5c3ff57be084dfac72dfb77f19dacb54c`、PostgreSQL 18.6、Redis 8.2.1 和模拟 Steam／AI。首个目录窗口 8 个 App 中自动发布 2 个。测试通过首页和目录确认自动收录，并覆盖 Consumer 410 恢复、Redis 与 Harvest 停机、成人状态屏蔽与恢复、31／181／365 天后的目录和合集。采集链路另验证 CN 免费和 US 零金额分离、价格过期、新闻来源和多平台单卡。
- 独立 CN／INTL 浏览器夹具验证 1280 px 与 390 px、触屏、暗色、Reduced Motion、IME、键盘提交、分页返回位置、图片失败回退和 Start 入口。独立 PostgreSQL 验证顺序编辑、版本冲突、错误回滚、游标失效、多合集归属及归档恢复。模拟数据库停机确认 API／SSR 状态为 503，恢复后为 200。
- 本地通过 Go、sqlc、Web 构建与类型检查、Catalog 浏览器、Harvest 联调、HMR 和容器健康启停。Docker Hub 在本机获取匿名令牌失败，使用同版本 AWS 公共镜像重新构建 Compose 镜像。匹配提交的远端结果见 [develop 的 GitHub Actions](https://github.com/librecosta/gofurry/actions/workflows/check.yml?query=branch%3Adevelop)。

## 性能

Windows 11／Ryzen 7 5800H，Docker Desktop 16 vCPU、约 15.3 GiB 内存，PostgreSQL 18.6。每规模 12 次热请求，包含本地数据库往返、Go DTO 解码和目录／合集两次分页读取。P95 为样本最大值。
