# Runtime boundaries

- `apps/web`: TanStack Start + React SSR, SCSS/CSS Modules and Motion. Base UI Popover/Menu/Dialog/Tabs/Radio primitives retain positioning and accessibility; SCSS owns visuals and Motion owns entry/exit/selection/image timelines. Controlled roots use `AnimatePresence`, `Portal keepMounted` and `render` composition, with no competing CSS opacity/transform transitions. Nitro's Node preset produces a self-contained `.output`. `/start` loads public background metadata after hydration through one regional API (`WEB_API_BASE_URL`); image bytes go directly from CDN. Preview and decoded AVIF overlap. API availability never blocks rendering or normal search.
- `services/api`: one Go module pinned to 1.27.3. Cobra requires one explicit `--config` path; Viper validates only that YAML, without environment bindings, search or merge. JSON adapters use standard-library v2/jsontext. `internal/server` owns Fiber, readiness and shutdown; middleware and handlers retain their existing boundaries.
- Middleware order: Request ID → Contrib Zerolog → Recover → Helmet → probes/routes. The outer logger asks Fiber's error handler to render before logging, so errors and panics receive their actual status and correlated ID. Logs use an allowlist of fields.
- API readiness becomes true in `OnListen`, false in `OnPreShutdown`. `GracefulContext` drains requests for up to 10 seconds; post-shutdown hooks close local readers/clients. No business database or scheduler exists. Optional S3-compatible storage uses bounded HTTP requests and explicit YAML credentials. Background routes return checked metadata only; the development import CLI is create-once and prefix-limited. No prefork is enabled. Forwarded client IPs are ignored unless YAML explicitly names trusted proxy peers/CIDRs; Fiber validates and strips that chain, with no broad private/loopback trust.
- Optional `geoip.database_path` resolves relative to the one API YAML and opens/verifies a local DB-IP Lite City MMDB at startup. The Start location handler does local `netip` lookups only, returns approximate city metadata or unavailable, and is private/no-store and independently rate-limited. It accepts no supplied-IP lookup and logs no client addresses/coordinates. Web SSR does not forward visitor IPs; see `docs/v0.1-c1-weather.md` for the direct-edge Nginx contract, attribution and manual file updates.
- Optional QWeather current weather uses that validated city only. One regional Provider reads a PKCS#8 Ed25519 key once, reuses and refreshes JWTs in memory, and reads Host/IDs/proxy only from the same YAML. Private key paths resolve against the YAML; `data/private/` stays ignored. The per-instance coordinate/language cache caps 512 entries and 4 merged-key flights, with 20-minute Fresh / under-60-minute Stale and failure cooling. HTTP quotas are separate; no arbitrary coordinate/IP endpoint, environment proxy or background poller exists. Return original provider attribution and bounded ready/stale/unavailable data, never a JWT or raw upstream error. Post-shutdown cancels requests and closes the Transport. The Start widget fetches only its URL locale after hydration, validates deployment Region/SFW headers, cancels replaced work and rechecks after 20 minutes on visibility return. Display-only data stays in React memory; no coordinates or complete response are persisted. Its Base UI/Motion Popover displays sources and safe original attributions. The production Web relay forwards only `lang`, never visitor IP headers; real resolution remains the trusted direct-edge API's responsibility.
- Start locale is owned by the deployment-relative URL: CN `/start` + `/en/start`, INTL `/start` + `/zh/start`. Cookie only remembers it; no IP/browser/Cookie redirect overrides an explicit URL. A pathless Start shell preserves background/dialog/search instances across language navigation. Start is noindex; future indexable routes own canonical/hreflang.
- Theme preference is system/light/dark, stored in a host-only cookie. CSS media-query themes render system colors before JS; React tracks the resolved OS theme after hydration without changing the initial tree. Region remains deployment-owned. INTL may persist an SFW/NSFW preference, while actual API content and suggestion policy remain SFW; CN renders no NSFW controls. No user-data clients exist; future readers stay inside their region. Personalized responses are private/no-store.
- `styles/tokens.scss` contains one Light palette and Dark overrides, including search material roles. `themes.scss` emits inherited CSS properties, with system colors selected by media queries before hydration. The root links `global.scss?url` (fonts/reset/themes); Vite/Start load route CSS Module assets before their components. No styling runtime or virtual stylesheet exists. Keep Start before React; SCSS HMR and Fast Refresh share the existing `task check:hmr` entry point. Native circular theme snapshots remain separate from Motion. See `docs/v0.1-c0.md` for the A/B/C evidence and retained Base UI boundary.
- Production access logs retain errors and slow requests; fast successful requests/probes are skipped through official Contrib hooks. Compose uses compressed local rotation 5m × 3, a read-only explicit API YAML mount, host ports 17320/17321 on loopback and a 20-second stop window. There are no production integrations; Nginx remains an inactive example.

Do not turn reference template directories into empty scaffolding. Add business boundaries, persistence and reusable packages only when real functionality requires them.
