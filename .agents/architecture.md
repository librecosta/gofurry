# Runtime boundaries

- `apps/web`: TanStack Start + React SSR, StyleX and one Base UI Popover. Nitro's Node preset produces a self-contained `.output`. The Web does not depend on API availability to render or report health.
- `services/api`: one Go module pinned to 1.27.3. Cobra requires one explicit `--config` path; Viper validates only that YAML, without environment bindings, search or merge. JSON adapters use standard-library v2/jsontext. `internal/server` owns Fiber, readiness and shutdown; middleware and handlers retain their existing boundaries.
- Middleware order: Request ID → Contrib Zerolog → Recover → Helmet → probes/routes. The outer logger asks Fiber's error handler to render before logging, so errors and panics receive their actual status and correlated ID. Logs use an allowlist of fields.
- API readiness becomes true in `OnListen`, false in `OnPreShutdown`. `GracefulContext` drains requests for up to 10 seconds; post-shutdown hooks own future resource cleanup. No database, scheduler or other owned resource exists yet. No prefork or trusted proxy configuration is enabled.
- Web themes/locales use sanitized host-only cookies serialized into root route context; SSR and hydration agree. Without a preference, the theme defaults to Light. Region is deployment-owned (Web server setting / API YAML), never chosen by locale or cookies. CN is always SFW; INTL defaults SFW with no NSFW implementation. No user-data clients exist; future data access must stay inside the selected region. Personalized responses are private/no-store.
- Production CSS is linked from a single root CSS entry including local font imports. Development uses official virtual CSS/HMR. Keep Start before React and StyleX before Fast Refresh. Optional StyleX source-line debug attributes are disabled because Start's server/client route transforms shift line numbers independently; dev classes/HMR remain enabled.
- Production access logs retain errors and slow requests; fast successful requests/probes are skipped through official Contrib hooks. Compose uses compressed local rotation 5m × 3, a read-only explicit API YAML mount, host ports 17320/17321 on loopback and a 20-second stop window. There are no production integrations; Nginx remains an inactive example.

Do not turn reference template directories into empty scaffolding. Add business boundaries, persistence and reusable packages only when real functionality requires them.
