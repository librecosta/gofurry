# GoFurry brand assets

The symbol uses the four original paths and their transform from [`logo-mini.svg`](../../src/assets/logo-mini.svg), which match the legacy navigation SVG. The embedded Potrace credit is retained. The OG and favicon use the legacy icon's orange `#E5583D` artwork and light peach `#FFDEC2` background. The standalone symbol and horizontal artwork use the same orange on transparent backgrounds. [Legacy icon PNG](https://github.com/gofurry/gofurry-nav-site/blob/0b0df139f3c85d1238160a6f0ee2cbd007736c6d/apps/cn/nav-web/public/logo-mini.png)

The English wordmark uses DM Sans 700 with HarfBuzz kerning and −0.035 em tracking, following the Tool4Furry reference. FontTools converted the glyphs from `@fontsource-variable/dm-sans@5.3.0` (`dm-sans-latin-wght-normal.woff2`) to paths. Copyright 2014 The DM Sans Project Authors, SIL Open Font License 1.1. [DM Sans license](https://github.com/librecosta/tool4furry/blob/a14429a384b2cd7df6fc475f5a30642560a368fa/public/licenses/dm-sans-OFL.txt) · [Tool4Furry artwork](https://github.com/librecosta/tool4furry/tree/a14429a384b2cd7df6fc475f5a30642560a368fa/public/brand)

Treat `logo-mini.svg` as the source for symbol geometry. Keep its paths and transform in sync across the three SVGs, and reuse the same wordmark outlines in the horizontal artwork and OG master. The favicon places the symbol at 78 px visible width on a 96 px circular backplate and centers it by its visible bounds. After editing the OG master, export the PNG at the SVG's native 1200 × 630 size with resvg. The current PNG was exported with `resvg-py==0.5.0`.
